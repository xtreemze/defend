# Focused game-design chapters

These documents extend `../GAME_DESIGN_MANUAL.md` with focused, implementation-facing design chapters while the main manual remains the concise canonical synthesis.

- [`ENERGY_FLOW_AND_WORLD_ECOLOGY.md`](./ENERGY_FLOW_AND_WORLD_ECOLOGY.md) — physical teal energy spill/collection, silo siphoning, raider evacuation, mothership settlement/raid choice, distant teal signatures, and the larger silo/mothership ecology.

Focused chapters use the same semantics as the main manual:

- **Canonical principle** — identity-level requirement.
- **Current baseline** — measurable existing behavior useful for parity.
- **Experimental hypothesis** — requires certification before becoming production balance.
